# 🐍 Python Lab Questions

This repository demonstrates my learning and practice of **Python programming fundamentals**, including user input, variables, data types, arithmetic operators, conditional statements, mathematical calculations, and basic problem-solving.

> **Learn → Practice → Build → Commit → Improve**

## 📌 About This Repository

The purpose of this repository is to maintain my Python laboratory programs in a structured and version-controlled environment.

Each program is:

- Written in Python 3
- Tested locally before committing
- Organized using a clear naming convention
- Committed separately using Git
- Pushed and maintained on GitHub

This repository also provides practical experience with **Git and GitHub version control**.
